# ChemHub 维护与验证

ChemHub 仅保留正式的紧凑深色首页：`index.html`、`design.css`、`app.js` 与 `tools.js`。此前的设计方案、比较页、旧主题与相关截图已经移除，不再维护或测试。

## 资源与分类

- 当前收录 76 个资源、12 个分类；资源只追加到 `tools` 数组末尾，索引、URL 与图标身份保持稳定。
- 「文献专利搜索」（原「文献专利」）有 7 项；Chemistry Reference Resolver 位于该分类首位。旧的折叠记录会兼容映射到新分类名称。
- 「学术期刊」有 10 项。MDPI、Thieme Connect、Taylor & Francis Online 暂用 `icon:false` 文字标识，不请求缺失图片。
- 图标容器固定 32px，图片显示 16px；本地图标与来源记录位于 `assets/icons/`。

## 正式首页交互

支持搜索、分类筛选、网格／列表切换、键盘操作、移动端布局及分类独立折叠。无已保存偏好时分类默认折叠；搜索或单分类筛选会临时展开结果。

顶部「置顶工具」仅保存当前浏览器和同源下的有效资源 URL，使用键 `chemhub.pinned-tools.v1`；其与分类折叠、资源索引和个人预览收藏相互独立。存储不可用时，页面明确提示仅当前页有效。

宽度达到 1440px 时，首页正文两侧保留更宽的空白区域；窄屏恢复普通边距。页面不显示广告预留框。

## 验证

```sh
node tests/build.cjs
node tests/designs.cjs
```

`tests/build.cjs` 验证发布白名单、图标模式、构建失败保护与字节一致性。浏览器测试覆盖正式首页资源链接和搜索、图标降级、分类折叠及旧偏好迁移、宽屏左右留白、个人置顶、HTTP／本地文件及受限存储；不再生成截图或测试设计预览。
